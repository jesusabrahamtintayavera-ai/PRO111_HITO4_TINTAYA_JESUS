# PRO111_HITO4_TINTAYA_JESUS
Descripción breve del problema resuelto
El proyecto resuelve la necesidad de determinar automáticamente la condición académica de un estudiante a partir de su asistencia y su calficación final. El programa calcula el porcentaje de asistencia y, según las reglas establecidas, indica si el estudiante está aprobado, reprobado por nota o reprobado por asistencia.
 Requisitos para ejecutar el programa
Tener instalado Python 3.10 o superior (para la versión en Python).
Contar con un entorno de desarrollo como Visual Studio Code, IDLE o cualquier intérprete de Python.
Para la versión en PSeInt, tener instalado el software PSeInt.
Disponer del código fuente del programa.
 Instrucciones de ejecución paso a paso
En Python
Abrir Visual Studio Code o el entorno de desarrollo de preferencia.
Crear un archivo con extensión .py.
Copiar y pegar el código fuente del programa.
Guardar el archivo.
Ejecutar el programa.
Ingresar los datos solicitados:
Nombre del estudiante.
Clases programadas.
Clases asistidas.
Calificación final.
Observar los resultados mostrados en pantalla.
Ejemplo de uso con datos de prueba
Datos de entrada:
Nombre: Juan Pérez
Clases programadas: 40
Clases asistidas: 36
Calificación final: 75
Proceso:
Asistencia = (36 / 40) × 100 = 90%
Resultado:
Porcentaje de asistencia: 90%
Condición: Aprobado
